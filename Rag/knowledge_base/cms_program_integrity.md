## Program Integrity

CMS describes program integrity activities aimed at identifying and preventing fraud, waste, and abuse.

CMS resources include material related to:

- Medical review
- Program integrity
- Correct coding
- Improper payments
- Fraud, waste, and abuse prevention
- Provider compliance

---

## Correct Coding

CMS's National Correct Coding Initiative (NCCI) promotes correct coding methodologies and is intended to reduce improper coding and improper payments.

When a model identifies unusual procedure-related behavior, investigators may consider reviewing coding and procedure patterns against applicable coding guidance.

---

## Medical Review

CMS describes medical review activities that can be used to identify and address improper claims.

When a provider is flagged by an analytical model, the model output can be treated as a signal for additional review rather than as a final determination.

---

## Fraud, Waste, and Abuse

CMS provides resources concerning the identification, prevention, and reporting of fraud, waste, and abuse.

Analytical signals should therefore be interpreted as potential indicators requiring appropriate review.

---

## Investigation Context

CMS's program-integrity resources emphasize analytical and review activities for protecting Medicare and Medicaid programs.

The RAG system should use these sources to provide contextual information and should not present model predictions as confirmed fraud.
